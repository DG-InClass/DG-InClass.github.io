JavaScript files are simply text files with the extension `.js`. Here's an example.

```js title="demo.js"
console.log('Hello World!');
```

Typically, we see these files used with websites, because JavaScript was originally created to run in web browsers.

Years ago, this would mean that anyone who wanted to learn JavaScript would first need to:

- Know at least a little bit of the HTML language,
- Create an HTML file to reference/use the JavaScript file,
- Open the HTML file in the browser, and
- Use the browser dev tools to see simple output.

That's a lot, particularly if you haven't ever seen HTML before.

## A Better Intro to JavaScript Programming

Nowadays, it's a **lot** easier to get started with JavaScript, all on its own. That's because of <a href="https://nodejs.org/" target="_blank">**NodeJS**</a>. In this tutorial, we'll get our first introduction to JavaScript. We'll be using the **Visual Studio Code** editor.

<Aside title="Required Software" type="caution">
  Make sure you have at least the following installed on your computer:

  1. **Visual Studio Code** (*VS Code*)
  1. **NodeJS**

  If you don't have those yet, go to the [System Setup](/general/0010/) article and get those two items installed. I also recommend you learn the basics of creating and editing files in VS Code as well as opening the VS Code terminal window.
</Aside>
