1. Hook up an event handler so that you have a place to process the user input. (You should see results in the browser's dev tools' console as you type in the input control.)

    You can try out the input control in the browser and watch what happens in your browser's console window.
1. Add some **state management** via React's `useState()` ***hook***. (A *"hook"* is simply a function that allows you to "participate" in React's *rendering lifecycle*.)

    ```diff lang="jsx" title="components/TodoList.js"
    + import {useState} from 'react';
      import { Box, Button, TextField, Grid } from '@mui/material';

      export default function TodoList() {
          // #region State Management
    +     const [todoText, setTodoText] = useState("");
          // #endregion
    ```

    Note how we give our initial `todoText` value an empty string (the argument passed into `useState()`).
1. Wire that into the `<TextField>` and the event handler.

    ```diff lang="jsx" title="components/TodoList.js" "onChange={onTodoTextChange}" "value={todoText}"
          // #region Event Handlers
          const onTodoTextChange = (event) => {
              console.log(event.target.value);
    +         setTodoText(event.target.value);
          }
          // #endregion

          return <>
            <TextField
              id="standard-basic"
              label="New Todo?"
              variant="standard"
              sx={{width: '100%'}}
              onChange={onTodoTextChange}
    +         value={todoText}
            />
    ```

    <Aside type="tip" title="Pair the onChange and value props">
      When you wire state to user input controls like the `<TextField>`, remember to hook up **both** the `onChange` and `value` props. Otherwise, your control will be "locked" in terms of its ability to capture state.
    </Aside>

1. Add some basic rendering of the data so you can see it in the browser.


1. Add another `useState()` to track the results of all the to-do items. Notice how we initialize the state with an *empty array* (a reasonable starting point for a list of information).

    ```diff lang="jsx" title="components/TodoList.js"
      export default function TodoList() {
          // #region State Management
          const [todoText, setTodoText] = useState("");
    +     const [allTodos, setAllTodos] = useState([]);
          // #endregion
    ```

1. Add a button to add items into our list of to-do tasks. We'll also put in an event handler for the button click event.

    ```diff lang="jsx" title="components/TodoList.js"
          // #region Event Handlers
          const onTodoTextChange = (event) => {
              console.log(event.target.value);
              setTodoText(event.target.value);
          }
    +     
    +     const onAddTodoClick = () => {
    +         // Temporary, just to confirm you've wired it up
    +         console.log("clicked"); 
    +         // create a new list that has allTodos and the new todos.
    +         const newAllTodoList = [...allTodos, todoText];
    +         console.log(newAllTodoList);
    +         // set the todoList
    +         setAllTodos(newAllTodoList);
    +         // reset the value of the todo text.
    +         setTodoText("");
    +     }
          // #endregion
    ```

    ```diff lang="jsx" title="components/TodoList.js"
            <TextField
              id="standard-basic"
              label="New Todo?"
              variant="standard"
              sx={{width: '100%'}}
              onChange={onTodoTextChange}
              value={todoText}
            />
    +       <Button
    +         variant="contained"
    +         onClick={onAddTodoClick}
    +       >Add Todo</Button>
            <Grid item xs={12}>
              Current input text: {todoText}
    ```

1. Render the information in a `<List>`.

    ```diff lang="jsx" title="components/TodoList.js"
      import {useState} from 'react';
      import { Box, Button, TextField, Grid } from '@mui/material';
    + // You can (probably should) combine the lines above and below
    + import { List, ListItem, ListItemText, Typography } from '@mui/material';
    ```


    ```diff lang="jsx" title="components/TodoList.js"
            <Grid item xs={12}>
    -         Current input text: {todoText}
    +         <List sx={{width: `100%`}}>
    +         {allTodos.map((todoItem, index)=> {
    +             return <ListItem key={index}>
    +             <ListItemText>
    +                 <Typography variant="p" component="div">
    +                 {todoItem}
    +                 </Typography>
    +             </ListItemText>
    +             </ListItem>
    +         })}
    +         </List>
          </Grid>
    ```
