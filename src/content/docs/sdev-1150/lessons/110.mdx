### HTML, CSS, and JavaScript

This lesson moves from project tooling into the browser page itself. The page already contains HTML and CSS. Students will add JavaScript so they can inspect the page, select elements, and update what the user sees.

Keep the language responsibilities separate:

- **HTML** provides structure and content.
- **CSS** controls presentation.
- **JavaScript** adds behaviour and can update the page while it is running.

The main idea is that JavaScript does not edit the original HTML file. JavaScript works with the page that the browser built from that HTML.

### The DOM

The DOM is the browser's object representation of the page. Once the browser reads the HTML, it builds a tree of objects. JavaScript can select objects from that tree, read them, and change them.

Students do not need the full DOM API today. They need the first habit: use JavaScript to find one element, store it in a variable, inspect it in the console, and then change one thing about it.

<Aside type="note" title="DOM Vocabulary">
  Use "HTML" for the source document and "DOM" for the live page structure in the browser.

  That distinction helps students understand why JavaScript can change the page without rewriting the `index.html` file.
</Aside>

### Selectors

The `document.querySelector()` method uses CSS-style selector strings. That means students can use selector patterns they may already recognize from CSS.

- `h1` selects the first `<h1>` element.
- `.container` selects the first element with the `container` class.
- `#brand-name` selects the element with the `brand-name` id.

Later, students can use `.querySelector()` from a specific element instead of from `document`. That lets them search inside one smaller part of the DOM.

### Browser Console

The browser console is the easiest place to confirm that JavaScript is running and inspect values selected from the DOM.

In this lesson, use the console deliberately. Do not treat `console.log()` as throwaway output. It is a way to ask the browser, "What did JavaScript find?"

### Select Elements From the DOM

`document.querySelector()` selects the first matching element from the DOM.

<Steps>
1. Select the page heading by tag name.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      console.log(courseCode);
      console.log(`Lesson number: ${lessonNumber}`);
    +
    + const pageHeading = document.querySelector('h1');
    + console.log(pageHeading);
    ```

    The selector string `'h1'` matches the first `<h1>` element.

1. Don't be confused by the output of `console.log(pageHeading)`. `pageHeading` is ***NOT* a string**! You can confirm this by including the folowing.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const pageHeading = document.querySelector('h1');
      console.log(pageHeading);
    + console.log(typeof pageHeading);
    + console.log(pageHeading.__proto__.constructor.name);
    ```

1. Let's resume with using other selector strings. Select the brand area by it's `id` attribute value.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const pageHeading = document.querySelector('h1');
      console.log(pageHeading);
      console.log(typeof pageHeading);
      console.log(pageHeading.__proto__.constructor.name);
    +
    + const brandName = document.querySelector('#brand-name');
    + console.log(brandName);
    ```

    The selector string `'#brand-name'` uses the same `#` pattern students may know from CSS id selectors.

    ```ps title="Browser Dev Tools Console"
      ▶ <li id="brand-name">…</li>
    ```

    Notice that we have the `▶` triangle. Have the students click on it to expand the HTMLElement and see its internal content.

1. Select the first container by class.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const brandName = document.querySelector('#brand-name');
      console.log(brandName);
    +
    + const firstContainer = document.querySelector('.container');
    + console.log(firstContainer);
    ```

    The selector string `'.container'` uses the same `.` pattern as CSS class selectors.

    <Aside type="caution" title="First Match Only">
      `querySelector()` returns the first matching element.

      This page has more than one `.container`, but this line only selects the first one. That is enough for today; Lesson 14 will go deeper with selecting multiple elements.
    </Aside>

1. Try a selector that does not match anything.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const firstContainer = document.querySelector('.container');
      console.log(firstContainer);
    +
    + const missingElement = document.querySelector('.missing-card');
    + console.log(missingElement);
    ```

    The console shows `null`. That means JavaScript searched the DOM but did not find a matching element.
</Steps>

### Search Inside a Smaller Part of the Page

Once JavaScript has selected an element, it can search inside that element.

<Steps>
1. Select the main page area.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const missingElement = document.querySelector('.missing-card');
      console.log(missingElement);
    +
    + const mainContent = document.querySelector('main');
    + console.log(mainContent);
    ```

1. Search for the list inside `mainContent`.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const mainContent = document.querySelector('main');
      console.log(mainContent);
    +
    + const languageList = mainContent.querySelector('ul');
    + console.log(languageList);
    ```

    This is still a tag selector, but it searches inside `mainContent` instead of searching the whole document.

    <Aside type="note" title="Subset of the DOM">
      Searching from a smaller element is a useful habit.

      It makes the selector more specific without needing to create more ids in the HTML.
    </Aside>

1. Compare and constrast the results of searching for the first `ul` in the document as a whole.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const languageList = mainContent.querySelector('ul');
      console.log(languageList);
    +
    + const firstUnorderedList = document.querySelector('ul');
    + console.log(firstUnorderedList);
    ```

</Steps>

### Modify Content, Attributes, and Styles

Now that students can select elements, they can change the live page.

<Steps>
1. Change the heading text.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      console.log(firstUnorderedList);
    +
    + pageHeading.textContent = 'JavaScript Can Update the DOM';
    ```

    The browser updates the visible heading. The original `index.html` file does not change.

    <Aside type="caution" title="Prefer .textContent over .innerText">
      Most of the time, the choice between using `.innerText` and `.textContent` is not relevant. There are subtle differences between the two, but those won't appear until the student well beyond this course.

      However, to simplify the **automated testing** (jsdom), instruct the students to **use `.textContent`** instead of `.innerText`.
    </Aside>

1. Change text inside the brand area.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      pageHeading.textContent = 'JavaScript Can Update the DOM';
    +
    + const brandLabel = brandName.querySelector('strong');
    + brandLabel.textContent = 'Dynamic DOM';
    ```

    This uses a selected element, `brandName`, as the starting point for another query.

1. Use trusted HTML markup to replace the language list.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const brandLabel = brandName.querySelector('strong');
      brandLabel.textContent = 'DOM Demo';
    +
    + const threeTrustedLanguages = `
    +   <li><strong>HTML</strong> gives the page <u>structure</u>.</li>
    +   <li><strong>CSS</strong> controls how the page <u>looks</u>.</li>
    +   <li><strong>JavaScript</strong> can <u>update</u> the live DOM.</li>
    + `;
    +
    + languageList.innerHTML = threeTrustedLanguages;
    ```

    `.innerHTML` treats the assigned string as HTML. That is useful when the JavaScript needs to insert markup, but it should only be used when the content assigned to `.innerHTML` is trusted.

    <Aside type="danger" title="Untrusted HTML">
      Do not put user-provided or untrusted content into `.innerHTML`. The browser parses the string as HTML, so dangerous markup can run code.

      For example, this string is not safe to assign to `.innerHTML`:

      ```html
      <img src=x onerror="alert('DANGER!');" />
      ```

      If the content is plain text, prefer `.textContent`.
    </Aside>

1. Change an image attribute.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const brandLabel = brandName.querySelector('strong');
      brandLabel.textContent = 'DOM Demo';
      const threeTrustedLanguages = `
        <li><strong>HTML</strong> gives the page structure.</li>
        <li><strong>CSS</strong> controls how the page looks.</li>
        <li><strong>JavaScript</strong> can update the live DOM.</li>
      `;
      languageList.innerHTML = threeTrustedLanguages;
    +
    + const asideImage = document.querySelector('aside img');
    + asideImage.setAttribute('width', '180');
    + asideImage.setAttribute('alt', 'A person building a website');
    + asideImage.src = './img/undraw_code-review_jdgp.svg';
    ```

    The `setAttribute()` method changes an HTML attribute on the live DOM element. Some attributes, such as `.src` are, are so relevant for the particular type of HTML Element that their attribute has a corresponding property available.

    <Aside type="tip" title="VS Code Intellisense">
      When we use `.querySelector()`, it's only promise is that it will either return an `HTMLElement` or `null`. We don't get anything more specific than that.

      That's the reason you don't see the `.src` appear in intellisense when typing `asideImage.src`.

      If you *really* want to see that intellisense, then add a JSDoc comment above your variable declaration.

      ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      + /** @type {HTMLImageElement} */
        const asideImage = document.querySelector('aside img');
      ```
    </Aside> 

1. Change a style.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      const asideImage = document.querySelector('aside img');
      asideImage.setAttribute('width', '180');
      asideImage.setAttribute('alt', 'A person building a website');
    +
    + languageList.style.borderLeft = '0.4rem solid var(--pico-primary)';
    + languageList.style.paddingLeft = '1rem';
    ```

    This applies **inline styles** through JavaScript. The larger styling job still belongs in CSS, but this is a clear way to see JavaScript changing presentation at runtime.

1. Import and use the supplied footer helper.

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      import '@picocss/pico/css/pico.green.min.css';
    + import { fillCredits } from './credits';
      
      console.log('Lesson 12 main.js loaded');
    ```

    ```diff lang="js" title="~/inclass/11/demo/js/main.js"
      languageList.style.borderLeft = '0.4rem solid var(--pico-primary)';
      languageList.style.paddingLeft = '1rem';
    +
    + fillCredits(2026, 'Stew Dent'); // Use YOUR name
    ```

    This helper is already in the starter. It selects the copyright spans in the footer and fills them with text.

    <Aside type="note" title="JavaScript-Only Changes">
      After the script tag, every visible update in this lesson happens from JavaScript.

      That is intentional. The HTML is already prepared so students can focus on selecting and changing DOM elements.
    </Aside>
</Steps>
