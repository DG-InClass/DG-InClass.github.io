## Define a Valid Custom Element

Custom element names need a hyphen. Define `user-card`:

```js
class UserCard extends HTMLElement {
  connectedCallback() {
    let username = this.getAttribute('username');

    this.innerHTML = `
      <article>
        <h2>${username}</h2>
        <slot></slot>
      </article>
    `;
  }
}

customElements.define('user-card', UserCard);
```

Expected behavior: `<user-card>` elements render without a naming error.

## Add Template or Shadow DOM Practice

Try a template string first. If you want the content isolated, attach shadow DOM:

```js
let shadow = this.attachShadow({ mode: 'open' });
shadow.innerHTML = `<article><slot></slot></article>`;
```

Use one approach and add a comment naming which one you chose.

## Create Cards Programmatically

Use the starter `users` array:

```js
let list = document.querySelector('#user-list');

for (let user of users) {
  let card = document.createElement('user-card');
  card.setAttribute('username', user.username);
  card.textContent = user.role;
  list.append(card);
}
```

Expected browser behavior: one card appears for each user.
